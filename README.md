# 習志野市 テニスコート空き状況チェッカー

ちば施設予約システム（PC版）の「施設名から探す → 空き状況」画面を、ログインせずに閲覧して
習志野市の公営テニスコート4館の空き状況をまとめて取得します。**予約・ログイン・カート操作は一切行いません。**

対象: 秋津総合運動公園(A–F) / 芝園公園(A–D) / 袖ケ浦運動公園(A–D) / 実籾テニスコート(A–F)

## 使い方

### いちばん簡単な方法
`run.bat` をダブルクリック → 取得が終わると `results\latest.html` がブラウザで開きます。
（既定: 今日から受付期間の終わりまでの土日祝。4館で数分〜10分程度）

### コマンドで実行
```
cd C:\Users\yhiot\tennis-checker
python checker.py [オプション]
```

| オプション | 意味 |
|---|---|
| `--days N` | 今日から N 日先までに限定（例: `--days 14` で2週間分） |
| `--all-days` | 平日も含める（既定は土日祝のみ。祝日は jpholiday で判定） |
| `--start YYYYMMDD` | 開始日を指定（既定: 今日） |
| `--venues U4020 U4070` | 館を絞る（U4020 秋津 / U4030 芝園 / U4040 袖ケ浦 / U4070 実籾） |
| `--open` | 終了後に latest.html をブラウザで開く |

`run.bat` にも同じオプションを渡せます（例: `run.bat --days 14`）。

## 出力（`results\` フォルダ）

- `YYYYMMDD_HHMM.json` … 全コマのデータと実行情報（所要時間・遷移数・注意事項）
- `YYYYMMDD_HHMM.csv` … 同じデータの表（Excelで開ける UTF-8 BOM 付き）。列: date, venue, court, start, end, status, venue_cd, icd
- `latest.html` … 日付 × 館 × コート × 時間帯 のマトリクス。空きは緑。「空きのみ表示」チェックで空きだけに絞り込み。

status の値: 空き / 予約 / 保守 / 休館 / 一般開放 / 雨天 / 受付期間外 / 時間帯なし

## 動作の仕組み・注意

- サイトは画面遷移の順序をサーバー側で管理しているため、毎回トップ → 施設名検索（習志野市・「テニス」）→ 館選択 → 日付ごとに表示更新、の順に辿ります。
- 1館につき1日あたり 1〜2 ページ（5面を超える秋津・実籾は2ページ目も取得）。
- **遷移ごとに3秒以上**間隔を空けます。エラー時はセッションを作り直して **1回だけ** 再試行し、それでも失敗したらその館の残りをスキップします。
- 各館とも、全コマが「受付期間外」になった日で打ち切ります。安全上限は120日。
- **予約済コマが1件も無い月**（例: 2〜3か月先）は、抽選・予約受付前のため「空き」と表示されている可能性が高いです。該当月は latest.html 末尾と JSON の notes に注意書きが出ます。
- 時間帯は館・日付によって変わります（例: 実籾は祝日 8:30 開始）。表示はサイトの値そのままです。
- 予約は公式サイト（https://www.cm1.eprs.jp/yoyaku-chiba/w/）から行ってください。
